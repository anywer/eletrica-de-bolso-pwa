ELÉTRICA DE BOLSO PWA 0.8.1

ABRIR NO COMPUTADOR
1. Extraia o ZIP.
2. Na pasta extraída, inicie um servidor HTTP local.
   Exemplo com Python instalado: python -m http.server 8080
3. Abra http://localhost:8080 no Chrome ou Edge.
4. Use o botão "Instalar" quando ele aparecer.

ABRIR NO CELULAR
1. Publique os mesmos arquivos em qualquer hospedagem estática HTTPS gratuita,
   ou sirva a pasta em sua rede local.
2. Abra o endereço no navegador.
3. No menu, escolha "Adicionar à tela inicial" ou "Instalar aplicativo".
4. Depois da primeira abertura completa, o app funciona offline.

PRIMEIROS PASSOS
1. Crie uma conta, confirme o e-mail recebido e entre.
2. Clientes > + Cliente.
3. Cadastre o imóvel/obra e crie um projeto diretamente nele.
4. Planta > + Cômodo; selecione uma ferramenta e toque dentro do cômodo.
5. Para um trecho, toque em "Trecho", depois em dois pontos e informe o comprimento.
6. Dimensionamento > Atualizar pela planta; revise todas as premissas e proteções.
7. Manutenções > registre cada visita/serviço.
8. Backup > baixe um JSON regularmente.

IMPORTANTE
Os cálculos e registros são preliminares. Não representam aprovação normativa.
Exigem validação em campo por profissional habilitado segundo a NBR 5410 vigente,
regras da distribuidora, esquema de aterramento e proteções aplicáveis.

DADOS
Os dados ficam no aparelho para uso offline e são sincronizados no Firestore da conta.
Cada conta usa uma área própria. Guarde também backups JSON fora do aparelho.
